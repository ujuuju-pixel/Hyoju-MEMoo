# 효주어 메모 앱

아이폰 Safari와 GitHub Pages에서 사용하는 효주어 전용 메모 앱입니다.

## GitHub에 올리는 방법
1. 이 ZIP 파일을 아이폰 `파일` 앱에서 탭해 압축을 풉니다.
2. GitHub 저장소의 **Code** 화면에서 초록색 `Code` 버튼 오른쪽의 `…` 버튼을 누릅니다.
3. `Upload files`가 보이면 선택합니다. 보이지 않으면 Safari 주소창의 `가가` 또는 페이지 메뉴에서 **데스크탑 웹 사이트 요청**을 켠 뒤 다시 확인합니다.
4. 압축을 푼 `hyoju-memo-final` 폴더 안의 파일과 폴더를 전부 업로드합니다. 저장소 첫 화면에 `index.html`이 바로 보여야 합니다.
5. 아래의 `Commit changes`를 누릅니다.

## GitHub Pages 켜기
1. 저장소 상단 `More` → `Settings`로 갑니다.
2. `Pages`를 엽니다.
3. Source를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`를 고르고 `Save`를 누릅니다.
5. 잠시 뒤 표시되는 주소를 Safari에서 엽니다.
6. Safari 공유 버튼 → `홈 화면에 추가`를 누릅니다.

## 주의
- 데이터는 아이폰 Safari의 localStorage에 자동 저장됩니다.
- Safari 방문 기록/웹사이트 데이터를 삭제하면 메모가 사라질 수 있습니다.
- 다른 기기와 자동 동기화되지는 않습니다.
